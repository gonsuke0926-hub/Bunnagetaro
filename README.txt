スクショはローカルAIにぶん投げろ！ v1.3.0
==========================================

囲った範囲の画像を PC の AI（Ollama）に送り、答えをキャプチャ枠の中に
透過表示する Windows 向けツールです。

画像は、プリセットごとに設定した指示（プロンプト）と一緒に送ります。
翻訳・OCR・数式・表の読み取りなどに使えます。内蔵 OCR（PP-OCRv6）で
読み取った文字を送ることもでき、OCR だけなら Ollama なしでも使えます。
答えはそのままクリップボードにコピーでき、枠の外に表示することもできます。
ゲーム・PDF・動画・Web ページ・ほかのアプリなど、画面に映るものなら何でも対象にできます。


■ できること

  最初から4つのプリセットを用意しています。

  ・翻訳: 枠の中の文字を読み取り、日本語に翻訳します。
  ・OCR : 枠の中の文字を読み取り、テキストにします（Ollama 不要）。
  ・数式: 数式を読み取り、LaTeX や画像でコピーできます。
  ・表  : 表を読み取り、Excel にそのまま貼れる形でコピーできます。

  設定で、いろいろ自由に変えられます。

  ・使う AI モデルや指示を変える・自分用のプリセットを作る
  ・画面の区画を自動で検出し、枠の中では元の文字の位置に重ねて表示する（内蔵 OCR・VLM とも）
  ・枠の中と外窓それぞれの背景色・文字色・不透明度を設定する
  ・文字起こししてから AI に渡すか、画像のまま画像対応の AI（VLM）に渡すかを選ぶ
  ・画面が止まったら自動で読み取る・答えを自動でコピーする・答えに続けて質問する・
    タスクトレイに常駐する など


■ こんな時に

  ・翻訳されていないゲームで、台詞が取り出せない場面や、壁・看板など絵の中の文字を読みたい
  ・論文・教科書の数式や表を、LaTeX や表として取り出したい


■ 導入手順

  1. zip を展開して起動する
     ・ダウンロードした zip（Bunnagetaro-v1.3.0-win-x64.zip）を右クリックし、
       「すべて展開」で任意のフォルダへ展開します。
     ・展開した中の Bunnagetaro フォルダを開き、Bunnagetaro.exe を起動します。
       ※ exe だけを別の場所へ移動すると動作しません（同じフォルダの DLL や Models フォルダが必要です）。
         デスクトップ等から起動したい場合はショートカットを作成してください。
       ※ 初回起動時に Windows SmartScreen の警告が出た場合は、「詳細情報」→「実行」を選択してください。
     ※ プリセット「OCR」（内蔵 OCR のみ）を使う場合は、下の 2〜3（Ollama の導入）は不要です。

  2. Ollama をインストールする（翻訳・数式・表を使う場合）
     ・https://ollama.com/download から Windows 版をインストールします。
     ・インストール後、Ollama を起動します（タスクトレイにアイコンが表示されていれば起動中です）。

  3. モデルを取得する
     スタートメニューで「cmd」と検索してコマンドプロンプトを開き、
     使いたいプリセットのモデルを取得します。

     ・翻訳（PLaMo 3 Translate）
         ollama pull hf.co/pfnet/plamo-3-translate-0.8b-GGUF:Q4_K_M
       ※ PLaMo 3 Translate には、より大きい 2B・8B・31B の版もあります。PC の性能
         （GPU のメモリ）に余裕があれば、大きい版の方が翻訳の質が上がることが多いです。
         使う時は、設定ページのプリセット欄でモデル名を変更してください。
     ・数式（GLM-OCR）
         ollama pull glm-ocr
     ・表（PaddleOCR-VL 1.6）
         ollama pull hf.co/PaddlePaddle/PaddleOCR-VL-1.6-GGUF

     別の Ollama モデル（gemma4、qwen3-vl 等）を使う場合は、
     設定ページのプリセット欄でモデルと指示を変更してください。

  4. 接続を確認して使う
     ・「設定」→「AI接続」で「接続テスト」「モデル一覧を取得」を押します。
     ・「キャプチャ窓を開く」を押し、読みたい範囲に枠を合わせてバーの「ぶん投げる」を押します。


■ 既定プリセット

  ・翻訳：文字起こし → 内蔵OCR（PP-OCRv6 small）＋ PLaMo 3 Translate
  ・OCR ：内蔵OCRのみ（PP-OCRv6 small / medium 同梱。Ollama 不要）
  ・数式：画像そのまま ＋ GLM-OCR（右クリックで LaTeX / 画像コピー）
  ・表  ：画像そのまま ＋ PaddleOCR-VL 1.6（右クリックで Excel 用コピー）

  設定ページの「ぶん投げ方」から、プリセットごとに
  文字起こし（内蔵OCR / VLM）・画像そのまま・内蔵OCRのみ を切り替えられ、
  「読み取った位置に並べる」で枠の中の元の位置への重ね表示を切り替えられます。


■ 動作環境

  ・OS：Windows 10 / 11（64bit）
  ・Ollama：ローカルで起動していること（既定 URL：http://localhost:11434。内蔵 OCR のみ使う場合は不要）
  ・Microsoft Edge WebView2 Runtime：Windows 10 / 11 には通常標準搭載されています
  ・動作の目安：次の PC で、既定のプリセット（モデルを含む）が実用的に使える程度に
    動くことを確認しています（速くはありません）。専用の GPU がある PC では、より速く動きます。
      CPU：Intel Core 5 320（6 コア）／メモリ：16GB／GPU：CPU 内蔵（Intel Graphics）


■ 設定・ログの場所とアンインストール

  設定とログは %APPDATA%\Bunnagetaro5 に保存されます。
  アンインストール時は、展開したフォルダと %APPDATA%\Bunnagetaro5 を削除してください。
